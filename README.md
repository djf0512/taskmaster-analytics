# taskmaster-analytics

An end-to-end data pipeline and dimensional model using Taskmaster UK scoring data plus public attention data from APIs. Work in progress.

**Stack:** Python, DuckDB, dbt Core, Git/GitHub.

**Data credit:** Per-task scores from [silverdavi/taskmaster-uk-scores](https://github.com/silverdavi/taskmaster-uk-scores) (CC BY-SA 4.0), compiled from the Taskmaster fan wiki. Source data is not redistributed in this repo.
